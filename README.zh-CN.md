# UnitPlayer TV

[English](README.md) | **简体中文**

把安卓电视或电视盒子变成可以从手机投视频过去的设备。

在电视上打开 UnitPlayer TV，它就会出现在各种支持 DLNA 投屏的 App 的设备列表里。选中它，视频就在电视上全屏播放，手机变成遥控器。

> **状态：第一个预览版（0.1）。** 能接收、能播放。手机端发来的字幕、开机后自己在后台等着、电视上自己的视频库，这些还没做。

## 能做什么

- **通过 DLNA 接收视频**：同一个网络里的手机、电脑都能投过来。它是给安卓版 UnitPlayer 配套做的（那边的“投屏到电视”按钮），其他支持 DLNA 的投屏 App 也能用。
- **全屏播放**：MP4、MKV、WebM、MOV、TS、HLS 直播流等，电视自己能解码的都行。
- **电视遥控器能用**：确定键播放或暂停，左右键后退或前进 10 秒，返回键停止。
- **手机照样能控制**：暂停、拖进度、调电视音量、看播到哪了。
- **没有别的**：不要账号，没有广告，不收集任何数据。它在网络上只做一件事：读手机发来的那一个视频地址。

## 安装

UnitPlayer TV 没有上架应用商店。到 [Releases](../../releases/latest) 下载 `.apk`，用下面任一种办法装到电视上：

- **U 盘**：把文件拷进 U 盘，插到电视上，用电视的文件管理器打开。电视会问一次是否允许从这里安装。
- **adb**：在同一个网络里的电脑上操作（先在电视的开发者选项里打开“网络调试”）：

  ```sh
  adb connect <电视的地址>
  adb install UnitPlayerTV-0.1-1.apk
  ```

需要 Android 8.0 或更高。在一台 Android TV 12 的电视上测试过。

核对下载的文件：`UnitPlayerTV-0.1-1.apk` 的 SHA-256 是
`daa416b89c38d1c3e6ee757d0e23dfb39d8fb6708b482ca2ffa9cac9583293b7`。

## 使用

1. 在电视上打开 **UnitPlayer TV**。它会显示“可以投屏了”，以及它在列表里的名字。
2. 在手机上打开一个视频，点投屏按钮，选那个名字。
3. 看的时候让它一直开在电视上：只有它在前台时才接收。

手机和电视要连在同一个网络上。

## 需要知道的

- **字幕**：在手机上选的字幕现在带不过来。
- **必须开着**才能被找到。在电视上切到别的应用，它就停止接收。
- 能播什么取决于电视：电视解不了的格式会显示“这个视频在这里播不了”。
